# Спайк браузерного слоя (19.09.2026, ночь)

## Что выяснили

- **VPN.** Домашний интернет идёт через VPN на роутере, ВкусВилл отдаёт `/vpn-detected/`. Через SOCKS-туннель на <сервер> (вне РФ) сайт открывается и пускает в аккаунт. Значит, Playwright может жить на <сервер> рядом с ботом, отдельный российский сервер не нужен.
- **Ссылка share_basket без входа** показывает окно «С вами поделились товарами» с кнопкой «Проверить наличие товаров» и НЕ добавляет товары; после входа окно закрывается, корзина остаётся пустой.
- **Ссылка share_basket под входом** показывает окно `#js-lk-modal-shared-basket` с вкладками Сегодня/Завтра, по каждому товару «В наличии N шт» (`data-log-stock`, `data-max`), внизу «3 товара на сумму 873» и кнопка `#accept_share_basket` «В корзину». После клика товары в корзине аккаунта.
- **Страница корзины `/cart/`** после добавления: 3 товара, 881 ₽ (с упаковкой 8 ₽). У каждой строки `.js-delivery__basket--row` есть «В наличии: N шт» (`.js-delivery__basket--row__maxq`) и скрытый блок «Нет в наличии» (`.js-delivery__basket--row__wo_maxq.hidden`), который показывается при отсутствии. Адрес доставки подставлен из аккаунта (адрес владелицы), слот «Сегодня за 1 час».
- **Признак входа:** ссылка `.HeaderSubMenu__HeaderProfileALink[href="/personal/"]` есть только под входом.
- **Корзина сайта → приложение:** не проверено, владелица смотрит утром 19.09.

## Не выяснили

- **Форма входа по СМС:** вход прошёл между кадрами рекордера, снимка формы нет. Автосъёмка из чистого профиля (spike/login-form.mjs) зависла на клике «Войти». Селекторы `loginOpen`, `phoneSubmit`, `codeInput`, `codeSubmit` в selectors.json пустые, снять отдельно (можно без владелицы до шага с кодом).
- Капча на входе: неизвестно.

## Решения для кода

- `tools/cart.mjs`: открыть ссылку → дождаться `#js-lk-modal-shared-basket` → снять наличие из модалки (`data-log-stock`) → клик `#accept_share_basket` → перейти на `/cart/` → разобрать строки. Если модалки нет и нет признака входа → `auth_required`.
- Прокси: на сервере не нужен, локально для отладки `PROXY=socks5://127.0.0.1:1081` (туннель на <сервер> ключом `~/.ssh/<ключ>`).
- Сессия владелицы сохранена в `browser/profile` на компьютере. На сервер переносится копией папки профиля или повторным входом через бота.
