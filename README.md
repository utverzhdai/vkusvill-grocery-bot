# Продуктовый бот для ВкусВилла

Telegram-бот, которому пишут «собери корзину на карбонару, спагетти есть» или «нужны молоко, яйца, хлеб», а он сам находит рецепт с источником, подбирает товары в каталоге ВкусВилла, кладёт их в корзину вашего аккаунта с учётом наличия на вашем складе доставки и отвечает «Корзина собрана, можно оплачивать». Оплата и слот доставки остаются за вами в приложении ВкусВилла.

Работает на официальном [MCP-сервере ВкусВилла](https://mcp.vkusvill.ru/) и на Claude Code по подписке Claude, без оплаты API за токены.

## Что умеет

- Рецепт по названию: фото, ингредиенты, шаги и ссылка на источник. Рецепт «из головы» модели запрещён: сначала рецепты ВкусВилла, потом проверенные кулинарные сайты со сверкой 2–3 версий, потом ваш текст или ссылка.
- Корзина из рецепта или из списка покупок: разбирает на количества, вычитает то, что есть дома, подбирает конкретные товары из каталога, кладёт в аккаунт, проверяет наличие на вашем складе и подбирает замены отсутствующему.
- Правки словами после сборки: «убери яйца», «сыр подешевле», «удвой».
- Память: что есть дома всегда и временно, любимые и нелюбимые товары, история заказов и замен. Файлы markdown, их можно править руками.
- Индикатор «Работаю…» с бегущими точками, удаляется после ответа. «Новый заказ» сбрасывает диалог.
- Вход в аккаунт ВкусВилла по СМС прямо в Telegram, когда сессия протухла.
- Отвечает только владельцу: чужие сообщения игнорирует.

## Архитектура

```
Telegram ── long polling ──► src/main.js
                                │
                                ▼
                         src/handler.js      очередь на чат, фильтр владельца,
                                │            индикатор «Работаю», вход по СМС
                                ▼
                    src/engine/claude-code.js
                     claude -p (Sonnet, подписка), промпт через stdin,
                     рабочая папка workspace/
                                │
        ┌───────────────────────┼──────────────────────────┐
        ▼                       ▼                          ▼
  MCP ВкусВилла           WebSearch / WebFetch        workspace/memory/*.md
  поиск, детали,          рецепты, которых нет         что есть дома,
  аналоги, рецепты,       во ВкусВилле                 предпочтения, история
  ссылка на корзину
                                │
                                ▼
                 Bash: node tools/cart.mjs <ссылка>
                 Playwright + Chromium в профиле с вашей сессией:
                 открывает ссылку корзины, жмёт «В корзину»,
                 читает /cart/ и «нет в наличии», отдаёт JSON
```

Почему нужен браузер: у MCP-сервера ВкусВилла пока нет авторизации, он отдаёт только ссылку «поделиться корзиной» и не знает ваш адрес. Playwright открывает эту ссылку под вашим входом, товары попадают в аккаунт, а страница корзины показывает наличие именно на вашем складе. Когда ВкусВилл выпустит MCP с авторизацией, этот слой можно будет отключить.

| Файл | За что отвечает |
|---|---|
| `src/main.js` | цикл long polling, сборка зависимостей |
| `src/handler.js` | маршрутизация сообщений, очередь, индикатор, поток входа по СМС |
| `src/engine/claude-code.js` | запуск `claude -p`, разрешённые инструменты, таймаут 3 минуты |
| `src/sessions.js` | сессии Claude Code по чату, 12 часов тишины, `state.json` |
| `src/photos.js` | маркеры `PHOTO:` и `AUTH_REQUIRED` в ответе модели |
| `src/telegram.js` | обёртка Telegram Bot API |
| `src/login-runner.js` | запуск входа по СМС, передача кода через файл |
| `workspace/prompts/system.md` | правила поведения модели |
| `workspace/mcp.json` | подключение MCP ВкусВилла |
| `workspace/tools/cart.mjs`, `cart-parse.mjs` | размещение корзины и разбор наличия |
| `workspace/tools/login.mjs` | вход по СМС |
| `workspace/tools/export-cookies.mjs`, `import-cookies.mjs` | перенос входа между компьютером и сервером |
| `workspace/tools/selectors.json` | CSS-селекторы страниц ВкусВилла, меняются при смене вёрстки |
| `workspace/memory/` | память бота |

Стек: Node.js 22+, Telegram Bot API, Claude Code CLI, MCP ВкусВилла, Playwright + Chromium, Vitest, systemd.

## Что понадобится

1. **Подписка Claude Pro или Max.** На своём компьютере установить Claude Code и один раз выполнить `claude setup-token`, получится токен вида `sk-ant-oat01-…`. Расход идёт в лимиты подписки, отдельных счетов нет.
2. **Бот в Telegram** от @BotFather (токен) и ваш Telegram ID (узнать у @userinfobot).
3. **Аккаунт ВкусВилла** с адресом доставки и способом оплаты.
4. **Сервер с Node.js 22+ вне России:** из России Telegram API и Anthropic недоступны. Подойдёт любой VPS. ВкусВилл с зарубежного адреса открывается, проверено из Казахстана.

## Быстрый старт

```bash
git clone <этот репозиторий> && cd vkusvill-grocery-bot
npm ci
npx playwright install --with-deps chromium
cp .env.example .env      # заполнить четыре переменные
npm start
```

Переменные `.env`:

| Переменная | Что это |
|---|---|
| `TELEGRAM_TOKEN` | токен бота от @BotFather |
| `OWNER_ID` | ваш Telegram ID, бот отвечает только ему |
| `CLAUDE_CODE_OAUTH_TOKEN` | токен из `claude setup-token` |
| `VKUSVILL_PHONE` | номер телефона аккаунта ВкусВилла, формат `+79990000000` |

Первый заказ: напишите боту «собери корзину на карбонару». Бот скажет, что сессии ВкусВилла нет, и попросит код из СМС. Если вход по СМС через бота не сработает (форма сайта может измениться), есть запасной путь: войти во ВкусВилл в Chromium на своём компьютере через `node spike/record.mjs`, выгрузить cookies командой `node workspace/tools/export-cookies.mjs`, скопировать файл на сервер и загрузить `node workspace/tools/import-cookies.mjs`.

Развёртывание как службы systemd: [DEPLOY.md](DEPLOY.md).

## Ограничения и честные оговорки

- Бот собран на Claude Code по подписке. Если Anthropic ограничит такой режим, движок меняется в одном файле `src/engine/claude-code.js` на вызов API любой модели с инструментами. Стоимость на API при ежедневных заказах: единицы рублей за заказ.
- Селекторы страниц ВкусВилла в `workspace/tools/selectors.json` привязаны к текущей вёрстке сайта. При смене вёрстки их нужно обновить, тесты на снимках покажут, где.
- Вход по СМС через бота написан по документации формы, а не по живому снимку, и может потребовать правки селекторов.
- Один бот обслуживает одного владельца. Для нескольких людей нужно несколько экземпляров.
